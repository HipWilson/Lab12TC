# Laboratorio 12 - Teoría de la Computación

Cálculo lambda y programación funcional.
Lenguaje utilizado: **JavaScript (Node.js)**, con funciones flecha (`=>`) como lambdas.

## Video de ejecución

[Video de la demostración](https://youtu.be/wgyn2fxYzPk)

## Estructura

| Carpeta | Contenido |
|---|---|
| `problema1_teoria/` | PDF con las respuestas teóricas (reducción-β de NOT, recursión y ciclos, cuándo usar programación funcional) |
| `problema2_ordenar_diccionarios/` | Ordenar una lista de diccionarios por un key |
| `problema3_matriz_transpuesta/` | Matriz transpuesta como lista de listas |
| `problema4_eliminar_elementos/` | Eliminar elementos indicados de una lista |

## Cómo ejecutar

Requiere [Node.js](https://nodejs.org). Desde la raíz del repositorio:

```
node problema2_ordenar_diccionarios/ordenar_diccionarios.js
node problema3_matriz_transpuesta/transpuesta.js
node problema4_eliminar_elementos/eliminar_elementos.js
```
